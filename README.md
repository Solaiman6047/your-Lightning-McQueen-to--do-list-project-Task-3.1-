# Project description 
This is a personal to-do list program that helps McQueen track the tasks that need to be completed. 
# Features 
The program allows the user to: 
- Add a task
- View the current to-do list
- Mark a task as completed
- Remove a task
# How to use 
The user needs to enter the first letter of the action he wants to perform (e.g. **a** to add a task) and then follow the prompts displayed by the program. 
To quit enter **q**
